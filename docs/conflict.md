# Розбір конфлікту злиття (Merge Conflict)

## Суть конфлікту
Два розробники одночасно змінили значення параметра `indent_size` у файлі `.editorconfig` (один встановив `2`, інший `8`) в різних гілках і спробували злити їх у `main`. Git зупинив злиття.

## 1. Помилкове вирішення
**Дія:** Видалити маркери конфлікту, але залишити обидва рядки (`indent_size = 8` та `indent_size = 2`).
**Чому це погано:** Файл синтаксично коректний, але парсери просто застосують останнє значення (`2`). У конфігураціях такі "тихі" баги небезпечніші, ніж у коді.

## 2. Правильне вирішення
**Дія:** Домовитися про правильне значення (наприклад, `4`), видалити маркери та залишити лише один рядок.
**Чому це правильно:** Файл конфігурації не містить дублюючих ключів, які можуть призвести до непередбачуваної поведінки.
