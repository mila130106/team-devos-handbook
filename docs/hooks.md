# Локальний Git Hook (Pre-commit)

Оскільки папка `.git/hooks` не відстежується Git і не передається через репозиторій, кожен розробник налаштовує перевірку локально[cite: 3].

## Інструкція зі встановлення:
1. Перейдіть у системну паку вашого репозиторію: `.git/hooks/`.
2. Створіть файл без розширення з назвою `pre-commit`.
3. Додайте скрипт перевірки на зайві пробіли (trailing whitespace) у кінці рядків[cite: 3].
4. Надайте файлу права на виконання через термінал: `chmod +x .git/hooks/pre-commit`.
