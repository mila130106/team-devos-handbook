# Спільні налаштування середовища розробки

Цей документ описує базові конфігураційні файли проєкту, які забезпечують єдиний стиль коду для всіх учасників команди незалежно від їхнього редактора.

## 1. Файл `.editorconfig`
Файл `.editorconfig` допомагає підтримувати єдиний стилістичний формат для різних редакторів коду.

### Приклад конфігурації:
```ini
root = true

[*]
charset = utf-8
end_of_line = lf
indent_style = space
indent_size = 4
insert_final_newline = true
trim_trailing_whitespace = true
