# Інструкція з CI/CD

Цей документ описує базові етапи налаштування неперервної інтеграції для наших репозиторіїв.

## Лінтери
Тут налаштовуються інструменти для автоматичної перевірки стилю коду та пошуку потенційних помилок перед збіркою.

## Збірка
Опис кроків компіляції та підготовки артефактів проєкту для подальшого розгортання.

## Тестування
Правила запуску автоматичних модульних та інтеграційних тестів.

## Приклад розташування конфігурації
Усі файли конфігурації неперервної інтеграції зазвичай зберігаються у спеціальній папка репозиторію:
`.github/workflows/`
